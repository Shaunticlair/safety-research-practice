# Safety Research Practice

## Does showing the working help?

A **90-minute pilot take-home** about reasoning with and without visible chain of thought. Investigate a baseline comparison, choose a follow-up experiment, and explain your predictions and findings in a 1–2 minute video.

**Start with the [participant README](ninety-minute/README.md).**

- [Setup and experiment commands](ninety-minute/SETUP.md)
- [Original predictions](ninety-minute/PREDICTIONS.md)
- [Two-slide recording template](ninety-minute/slides_template/README.md)
- [AI-assistance logging instructions](ninety-minute/AI_LOGGING.md)
- [Submission log and timing record](ninety-minute/AI_LOGS.md)
- [Pilot timing feedback](ninety-minute/PILOT_FEEDBACK.md)
- [Public sources and attribution](ninety-minute/SOURCES.md)

Complete installation, model download, logging setup, and a microphone/screen-recording check before the timer. Reading, research, slides, and recording are inside the 90 minutes. Please record actual elapsed time and tell us how the scope felt.

The final submission is a small ZIP containing reproduction code and a completed `AI_LOGS.md` (including full task-related AI logs, original predictions, and timing feedback), plus an unlisted YouTube link that anyone with the link can watch. Keep model weights, checkpoints, environments, downloaded datasets, caches, large outputs, and the video file out of the submission ZIP.

The package includes a pinned Qwen3-8B configuration, task generator, exact grader, raw-output inspection, paired analysis, and a small cached baseline. Generator and slide-runtime license notices are included with their source files. This pilot still needs feedback from fresh participants about the 90-minute workflow.
